# queryproof Architecture

queryproof is a lightweight, deterministic verification engine designed to intercept SQL queries generated by LLMs and validate them before warehouse execution. It compiles to a standalone Go binary with an embedded React 19 visual workbench.

## 1. Engine Core Components

### 1.1 Lexer and Recursive-Descent AST Parser
The engine implements a zero-allocation tokenizer and recursive-descent parser in `internal/ast/`. It constructs an abstract syntax tree representing `SELECT` statements, `WITH` CTEs, projections, multi-table joins, boolean expressions, window functions, and nested subqueries across PostgreSQL, Snowflake, and BigQuery dialects.

### 1.2 Database Schema Catalog
The catalog (`internal/config/schema.go`) loads structural metadata from JSON or YAML files:
- Column data types and nullability constraints.
- Primary key and foreign key declarations.
- Explicit and inferred relationship cardinalities (1:1, 1:N, N:1, N:M).
- Estimated table row counts.
- Tenant isolation and soft-delete conventions.
- Partition key definitions for analytical engines.

### 1.3 Semantic Metric Layer (`metrics.yaml`)
Corporate KPI definitions live in `metrics.yaml` (`internal/metrics/`). The registry indexes approved formulas, required query filters, and permitted grouping dimensions. The expression comparator evaluates AST subtrees against approved KPI formulas to detect hallucinated variations.

### 1.4 Falsification Probe Suite
The suite (`internal/probes/`) executes five deterministic probes in parallel. Each probe evaluates mathematical invariants, records violations with severity tags (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`), calculates an integrity score, and recommends explicit AST remediation steps.

### 1.5 Deterministic AST Rewriter
When violations are flagged, the rewriter (`internal/ast/rewriter.go`) restructures the query AST:
- Injects pre-aggregated CTEs to isolate 1:N join fan-outs.
- Wraps arithmetic division with `NULLIF(denominator, 0)` and `COALESCE`.
- Wraps nullable columns in `AVG()` with `COALESCE(col, 0)`.
- Injects missing tenant isolation and soft-delete filters into `WHERE` clauses.

### 1.6 Cryptographic Integrity Voucher (`proof.json`)
The proof engine (`internal/proof/`) issues a tamper-evident voucher (`proof.json`). It records the original query SHA-256 hash, probe findings, applied AST mutations, the rewritten query hash, and an HMAC-SHA256 signature generated using a root authority key.

## 2. Memory Footprint and Runtime Performance

queryproof maintains a minimal footprint:
- Peak RAM consumption under load: under 2 MB (strictly within the 20 MB budget).
- Query verification latency: typically under 1 ms per query on commodity hardware.
- Zero CGO dependencies.
- Static assets compiled directly into the binary with Go embed.
